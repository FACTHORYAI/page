# Facthory's brand mark

Facthory's own logos, copied unmodified from the brand's source (the Facthory Design System).
The gradient mark goes on light grounds, its mono file (white and greys) on dark ones. A logo is
never recoloured, stretched, cropped or redrawn; the app icons are drawn from these files.

| File | What it is |
| --- | --- |
| `mark.svg` | The mark: a ribbon folded into an F, in the brand's gradient |
| `mark-mono.svg` | The mark in white and greys, for dark grounds |
| `mark.png` | The mark, 960 × 1016 pixels |
| `word-mark.svg`, `word-mark-only.svg`, `word-mark-only-mono.svg` | The mark beside "Facthory", and the lettering alone |
